How Architecture Affects Risk

Select an architecture and trigger a failure to see how different design approaches mitigate (or amplify) concentration risk. Red represents failed components.

🎯 Single Point

  • Simplest to build
  • Lowest operational cost
  • All users affected by any failure
  • High concentration risk

🔄 Redundancy

  • Automatic failover
  • No user impact during failures
  • Still single infrastructure
  • Higher costs

🌐 Distributed

  • Limits failure scope
  • Users in other regions unaffected
  • Complex to manage
  • Best resilience
